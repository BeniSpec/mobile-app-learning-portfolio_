# Module 2 – Source Code

`KotlinFundamentals.kt` — a standalone Kotlin file (run in Kotlin Playground style, no Android Studio project needed) demonstrating the five topics from Unit 2, Pathway 1: variables, conditionals, nullability, classes/objects, and lambda expressions.

`Lemonade.kt` — Compose code from Unit 2, Pathway 2 ("Add a button to an app"). A simplified step counter (1-4, wrapping back to 1) built with `remember { mutableStateOf(1) }` and a `Button` with an `onClick` lambda, focused on understanding Compose's state/recomposition model rather than the full image-swapping Lemonade UI.

See [`Module-2/Analysis.md`](../Analysis.md) for the full breakdown of each technique.
