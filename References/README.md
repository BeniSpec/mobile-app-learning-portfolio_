## Format to follow

**Webpage with an organization as author (most common for you):**
```
Organization Name. (Year). Title of the specific page (in italics). Site Name. URL
```

**Example:**
```
Google. (2026). Build a basic layout. Android Developers. https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-3
```
